## 建议的最小测量方式

至少选取一组脱敏历史投诉，记录同一案件在传统流程和 BE 流程中的：

1. 开始和结束时间；
2. 人工参与节点和 SQL 执行轮次；
3. 客户主张数量；
4. 实际需要的证据项；
5. 是否出现补证、返工或错误结论；
6. 最终是否经过人工确认。

报告中优先使用中位数，并同时报告样本数量。若只有演示样本，应写成“脱敏回放样本实测”，不要写成全量生产收益。
